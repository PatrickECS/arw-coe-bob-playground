# Use cases

## Validated customer and partner use cases

The Arrow Experience Center supports demonstrations and validations for customers and partners. Example use cases include:

### AI-assisted software engineering

- IBM Bob running on IBM Fusion on-prem, demonstrating AI-powered code writing, modification, and refactoring.
- Deployed as a containerized workload (Apache httpd serving a static webpage).

### Container platform validation

- Validating containerized workloads on IBM Fusion on-prem infrastructure.
- Demonstrating build, deploy, and run cycles for containerized applications.

## Validation criteria

Each use case is validated against:

- Successful deployment on IBM Fusion on-prem
- Accessible endpoint for demonstration
- Documented build and run procedure

## Note

These are example demonstration use cases. Validated customer and partner use cases are recorded by the AEC operations team and may differ from the examples shown here.
