# Operations

## Access

- Access to the Arrow Experience Center environment is granted through the standard onboarding process.
- Contact the AEC operations team to request access.

## Onboarding

1. Request access via the AEC operations team.
2. Complete any required security and access training.
3. Receive credentials and environment connection details.

## Operational procedures

- Demonstrations and proofs of concept are scheduled through the AEC booking process.
- Environment changes require coordination with the AEC operations team.
- All workloads are demonstration-grade; they are not production services.

## Security

- Never store passwords, tokens, API keys, or private keys in this folder or any AEC documentation.
- Distinguish production configurations from examples clearly.

## Support

- Contact the AEC operations team for environment issues or operational questions.
