# Arrow Experience Center

This folder contains technical and operational information about the Arrow Experience Center.

It is intended to provide IBM Bob with context when working on AEC-related tasks.

## Contents

- `environment.md` — Purpose and overall environment
- `infrastructure.md` — Compute, platform, storage and networking
- `services.md` — Available platforms and services
- `operations.md` — Access, onboarding and operational procedures
- `use-cases.md` — Validated customer and partner use cases

## Rules

- Keep information factual and concise.
- Update existing documentation instead of duplicating it.
- Never store passwords, tokens, API keys or private keys here.
- Clearly distinguish production configurations from examples.
